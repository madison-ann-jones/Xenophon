# TradeAdvisor Pro v2.0
A browser extension that provides algorithmic trading advice (Buy/Sell/Hold) for Stocks, ETFs, and Crypto across major exchanges like Binance, Robinhood, and Coinbase.

## Features
* Auto-detects assets on supported trading platforms.
* Evaluates market data using structural technical indicators.
* Bypasses CORS restrictions via Background Service Workers.

## Installation
1. Download the repository.
2. Go to `chrome://extensions/` in your browser.
3. Turn on "Developer mode".
4. Click "Load unpacked" and select this folder.
